# LMS студента

Локальный прототип на React, TypeScript, Vite, Tailwind CSS и shadcn/ui.
Экран «Навигатор» реализован по [макету NEW STUDENT в Figma](https://www.figma.com/design/kYv6AFlnXChycKIusOsvJC/NEW-STUDENT?node-id=46-7748).

```sh
npm install
npm run dev
```

Проверка сборки: `npm run build`.

PT Root UI подключён из `assets/PT-Root-UI`: regular, medium и bold. Заголовок использует Universita из `assets/Universita.otf`. Иконки, аватар и резервный кадр центрального визуала экспортированы из Figma в `public/assets/figma`; приложение не зависит от запущенной Figma и внешних шрифтов.

Над анимацией расположены виджеты погоды, следующей пары и дедлайнов. Все три виджета открывают shadcn/ui Popover при наведении, клавиатурном фокусе и нажатии на телефоне. В карточке пар — четыре ближайших слота с началом и окончанием, предметом, датой и форматом занятия. В домашках — четыре задания с названием, курсом и сроком сдачи. Внизу находятся кнопки «Открыть расписание» и «Открыть домашки». Списки отсортированы по времени; данные демонстрационные и хранятся в `src/data/study-widgets.ts`, время и счётчик на виджетах вычисляются из них. На небольших экранах длинный список прокручивается внутри карточки, кнопка перехода остаётся видимой.

Одновременно открыта одна карточка; переходы выполняются кнопками внутри. Стрелка вниз переводит фокус с виджета внутрь карточки, Escape закрывает её и возвращает фокус. Кнопки настройки позволяют скрывать и показывать виджеты и саджесты; выбор сохраняется до перезагрузки страницы. Саджесты: «Расписание сегодня», «Моя неделя», «Домашки», «Материалы». На десктопе поле ввода расположено внизу рабочей области, на небольших экранах содержимое доступно через прокрутку.

Настройки виджетов и саджестов открываются в отдельных модальных окнах shadcn/ui Dialog по центру экрана. Изменения применяются сразу. Диалог закрывается кнопкой «Готово», крестиком, нажатием снаружи или Escape; фокус возвращается на кнопку настройки.

Выбор саджеста добавляет внутрь поля промпта бейдж команды с `/`, например `/Расписание сегодня`. Введённый текст сохраняется, после команды можно дописать уточнение. Одновременно выбрана одна команда; другой саджест заменяет её. Крестик на бейдже и Backspace в начале текста убирают команду. Команда и текст передаются в форме отдельными полями `command` и `prompt`; отправка одной команды тоже доступна. До подключения помощника команда, текст и вложение сохраняются при попытке отправки.

Погода раскрывается в shadcn/ui Popover по [макету карточки](https://www.figma.com/design/kYv6AFlnXChycKIusOsvJC/NEW-STUDENT?node-id=56-9071): наведение и клавиатурный фокус открывают текущую погоду, прогноз и совет по одежде. Карточка остаётся открытой при переходе курсора внутрь, закрывается после ухода курсора, по Escape и нажатию снаружи. На сенсорном экране открывается и закрывается нажатием на виджет. Иллюстрация и иконки экспортированы из Figma и доступны локально; данные демонстрационные.

Основная навигация: «Навигатор», «Мои цели», «Обучение», «Расписание», «Хэндбук», «События», «Сервисы». «Обучение» раскрывает курсы, ведомости, зачетку, домашки, запись на пары, посещаемость и выбор курсов; «Сервисы» — Time, онлайн-запись и It-сервисы. Вложенные пункты не содержат иконок. Нажатие на группу в свёрнутом меню разворачивает навигацию и показывает её пункты. «Настройки» находятся внизу меню.

Центральный визуал — WebGL-анимация Orb из React Bits (исходник предоставлен вместе с заданием), адаптированная под TypeScript без дополнительных зависимостей. Три полупрозрачных слоя разного размера и фазы накладываются почти в одном центре и отрисовываются в одном canvas и WebGL-контексте. Частота ограничена 30 кадрами/с, DPR — 1.25. Область занимает 270 px по высоте на десктопе и 210 px на телефоне, не перехватывает клики и не перекрывает остальной интерфейс. Анимация реагирует на набор промпта и останавливается вне экрана, в скрытой вкладке и при включённом уменьшении движения. Если WebGL недоступен, используется резервное изображение.

Верхнее меню использует ghost-кнопки с клавиатурным фокусом, без всплывающих подсказок. Поле поиска пока принимает текст без выдачи результатов; ⌘/Ctrl + K переводит в него фокус. Работают сворачивание меню (⌘/Ctrl + B), мобильная навигация, панели закладок, уведомлений и профиля, подстановка примеров запросов и выбор вложения. Остальные разделы сохраняют пустую рабочую область исходного прототипа.

Помощник не подключён к серверу. При отправке появляется сообщение о недоступности; текст и вложение сохраняются в форме, файлы никуда не загружаются.
