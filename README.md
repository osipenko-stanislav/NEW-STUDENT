# LMS студента

Опубликованный интерфейс: https://osipenko-stanislav.github.io/NEW-STUDENT/
Изменения в ветке `main` автоматически публикуются через GitHub Actions.

Локальный прототип на React, TypeScript, Vite, Tailwind CSS и shadcn/ui.
Экран «Навигатор» реализован по [макету NEW STUDENT в Figma](https://www.figma.com/design/kYv6AFlnXChycKIusOsvJC/NEW-STUDENT?node-id=46-7748).

```sh
npm install
npm run dev
```

Проверка сборки: `npm run build`.
Все тесты: `npm test`.
Документация импорта хендбука: [docs/handbook/README.md](docs/handbook/README.md).
Для TypeScript-конфига Vite используется встроенный загрузчик `runner`, без предварительного бандлинга конфига.
Проверка хранения разговоров: `npm run test:storage` (Node.js 22.6+).
Проверка автоматических названий: `npm run test:titles`.
Проверка поиска: `npm run test:search`.
Проверка формата хранения материалов: `npm run test:materials`.
Проверка сценариев ассистента: `npm run test:assistant`.

PT Root UI подключён из `assets/PT-Root-UI`: regular, medium и bold. Заголовок использует Universita из `assets/Universita.otf`. Иконки, аватар и резервный кадр центрального визуала экспортированы из Figma в `public/assets/figma`; приложение не зависит от запущенной Figma и внешних шрифтов.

Над анимацией расположены виджеты погоды, следующей пары и дедлайнов. Все три виджета открывают shadcn/ui Popover при наведении, клавиатурном фокусе и нажатии на телефоне. В карточке пар — четыре ближайших слота с началом и окончанием, предметом, датой и форматом занятия. В домашках — четыре задания с названием, курсом и сроком сдачи. Внизу находятся кнопки «Открыть расписание» и «Открыть домашки». Списки отсортированы по времени; данные демонстрационные и берутся из общей учебной подборки `src/data/study-demo.ts` через `src/data/study-widgets.ts`, время и счётчик на виджетах вычисляются из них. На небольших экранах длинный список прокручивается внутри карточки, кнопка перехода остаётся видимой.

Одновременно открыта одна карточка; переходы выполняются кнопками внутри. Стрелка вниз переводит фокус с виджета внутрь карточки, Escape закрывает её и возвращает фокус. Кнопки настройки позволяют скрывать и показывать виджеты и саджесты; выбор сохраняется до перезагрузки страницы. Саджесты: «Расписание сегодня», «Моя неделя», «Домашки», «Материалы». На десктопе поле ввода расположено внизу рабочей области, на небольших экранах содержимое доступно через прокрутку.

Настройки виджетов и саджестов открываются в отдельных модальных окнах shadcn/ui Dialog по центру экрана. Изменения применяются сразу. Диалог закрывается кнопкой «Готово», крестиком, нажатием снаружи или Escape; фокус возвращается на кнопку настройки.

Выбор саджеста добавляет внутрь поля промпта бейдж команды с `/`, например `/Расписание сегодня`. Введённый текст сохраняется, после команды можно дописать уточнение. Одновременно выбрана одна команда; другой саджест заменяет её. Крестик на бейдже и Backspace в начале текста убирают команду. Команда и текст передаются в форме отдельными полями `command` и `prompt`; отправка одной команды тоже доступна. После отправки поле очищается, а команда отображается в сообщении пользователя.

Погода раскрывается в shadcn/ui Popover по [макету карточки](https://www.figma.com/design/kYv6AFlnXChycKIusOsvJC/NEW-STUDENT?node-id=56-9071): наведение и клавиатурный фокус открывают текущую погоду, прогноз и совет по одежде. Карточка остаётся открытой при переходе курсора внутрь, закрывается после ухода курсора, по Escape и нажатию снаружи. На сенсорном экране открывается и закрывается нажатием на виджет. Иллюстрация и иконки экспортированы из Figma и доступны локально; данные демонстрационные.

Основная навигация: «Навигатор», «Мои цели», «Обучение», «Расписание», «Хэндбук», «События», «Сервисы». «Обучение» раскрывает курсы, ведомости, зачетку, домашки, запись на пары, посещаемость и выбор курсов; «Сервисы» — Time, онлайн-запись и It-сервисы. Вложенные пункты не содержат иконок. Нажатие на группу в свёрнутом меню разворачивает навигацию и показывает её пункты. «Настройки» находятся внизу меню.

Центральный визуал — WebGL-анимация Orb из React Bits (исходник предоставлен вместе с заданием), адаптированная под TypeScript без дополнительных зависимостей. Три полупрозрачных слоя разного размера и фазы накладываются почти в одном центре и отрисовываются в одном canvas и WebGL-контексте. Частота ограничена 30 кадрами/с, DPR — 1.25. Область занимает 270 px по высоте на десктопе и 210 px на телефоне, не перехватывает клики и не перекрывает остальной интерфейс. Анимация реагирует на набор промпта и останавливается вне экрана, в скрытой вкладке и при включённом уменьшении движения. Если WebGL недоступен, используется резервное изображение.

Верхнее меню использует ghost-кнопки с клавиатурным фокусом, без всплывающих подсказок. Поиск в хедере и ⌘/Ctrl + K открывают центральный shadcn/ui Dialog с категориями «Все», «Курсы», «Материалы», «Домашки», «Разделы». Локальная фильтрация работает по названию и пути, учитывает все слова запроса, игнорирует регистр и различие «е/ё». Пустой запрос показывает быстрые переходы и до шести недавних разделов; они сохраняются отдельно от разговоров в `student-search-recent:v1`. Разделы индексируются из той же структуры, что и боковая навигация. Демообъекты явно отмечены и открывают соответствующий раздел, без вымышленных страниц курсов, материалов и заданий. ↑/↓ выбирают результат, Enter выполняет переход, Escape закрывает поиск с возвратом фокуса. Из пустой выдачи можно перенести запрос в поле «Навигатора» без отправки и создания разговора. Диалог учитывает видимую область экрана при появлении мобильной клавиатуры.

Работают сворачивание меню (⌘/Ctrl + B), мобильная навигация, панели закладок, уведомлений и профиля, подстановка примеров запросов и выбор вложения. Остальные разделы сохраняют пустую рабочую область исходного прототипа.

Первый запрос создает разговор с демонстрационным ответом ассистента; следующие сообщения продолжают его. Анимация и приветствие сменяются перепиской, поле ввода остается внизу, сообщения прокручиваются отдельно. «Навигатор» всегда возвращает чистый стартовый экран, не создавая пустого разговора. Вложенный пункт «История» раскрывает сохраненные диалоги прямо в боковой навигации. Название берется из первого запроса или команды. Меню `···` у каждого разговора позволяет переименовать его, закрепить или открепить и удалить после подтверждения. Закрепленные разговоры отмечены иконкой и идут первыми; внутри каждой группы порядок определяется последней отправкой сообщения. Переименование и закрепление не меняют время активности. Все изменения сохраняются после перезагрузки, прежние записи без признака закрепления поддерживаются. Кнопка меню появляется при наведении и фокусе с клавиатуры, на сенсорных устройствах видна всегда.

Автоматическое название формируется один раз при создании разговора: первые шесть слов саджеста и текста, до 60 символов, без `/` и пунктуации. Короткие запросы не дополняются искусственно; уточнение идет после названия саджеста. Ручное название и названия существующих разговоров не пересчитываются. Алгоритм вынесен в `src/lib/conversation-title.ts` и не использует LLM.

Переписка хранится в `localStorage` под ключом `student-conversations:v1` и восстанавливается после перезагрузки. Хранение и проверка формата вынесены в `src/lib/conversation-storage.ts`, состояние и действия — в `src/hooks/use-conversations.ts`. При недоступном хранилище переписка работает в памяти и показывается сообщение об ошибке сохранения. Сообщения состоят из типизированных сериализуемых блоков: текст, расписание, задания и учебные материалы. Тип и снимок данных сохраняются в истории; React-компоненты и HTML не сохраняются. LLM, MCP и бэкенд не подключены. Файлы хранятся в IndexedDB (`student-material-files`, хранилище `files`), метаданные и связи с разговорами — в localStorage (`student-materials:v1`). Кнопка с иконкой из макета перед профилем открывает правый сайдбар «Библиотека» со всеми загруженными файлами без затемнения и блокировки чата. На телефоне он занимает рабочую область под хедером; кнопка закрытия возвращает к чату. Меню «+» позволяет загрузить файл с устройства или выбрать существующий из библиотеки. Выбранные вложения видны в поле ввода и сохраняются в отправленном сообщении. Прикрепление в другой разговор использует тот же ID и Blob, без копирования файла. Удаление разговора сохраняет файлы и метаданные их происхождения. Удаление файла из библиотеки очищает его байты и выбранные вложения во всех разговорах; сообщения сохраняют название с отметкой «Файл недоступен». Снятие вложения в поле ввода не удаляет файл из библиотеки. Файлы не отправляются на сервер.

Клик по логотипу полностью сбрасывает сессию прототипа: удаляет все разговоры, материалы из IndexedDB, метаданные и недавние поисковые переходы, возвращает тему, настройки виджетов, подсказок и навигацию в исходное состояние. Обычный пункт «Навигатор» по-прежнему начинает новый разговор с сохранением истории. Сброс дожидается текущих операций с файлами; при ошибке очистки показывает сообщение и позволяет повторить действие.

Формат метаданных библиотеки имеет версию 2 под прежним ключом `student-materials:v1`: каталог файлов с `originId` хранится отдельно от выбранных вложений `attachments` с `scopeId`. Старый формат версии 1 читается с преобразованием `ownerId` в `originId`, без изменения ID и IndexedDB. Обновленный формат записывается при следующем изменении; повторное чтение и миграция не дублируют файлы. Привязки сообщений хранят ID файла и название; `materialId: null` обозначает удаленный файл. Полный сброс по логотипу по-прежнему очищает всю библиотеку.

Ассистент работает на детерминированных сценариях без внешних запросов. Общие учебные данные в `src/data/study-demo.ts` описывают фиксированную демонстрационную неделю 9–15 ноября 2026: «сегодня» — 11 ноября, «завтра» — 12 ноября. Виджеты, поиск и ответы используют одни занятия, задания и материалы. Движок `src/lib/mock-assistant.ts` сопоставляет команды и небольшой явный список фраз, учитывает последний сценарий в текущем разговоре и честно сообщает о неподдерживаемых запросах. Например: «А что у меня завтра?», «Покажи только домашки», «Какая ближайшая сдача?», «Найди материалы по математике», «Покажи сданные», «Покажи только PDF». Команду можно дополнить поддерживаемым уточнением: `/Моя неделя` + «покажи только домашки».

После отправки ответ появляется с короткой задержкой и постепенной печатью, затем раскрывается компактный интерактивный блок. При уменьшении движения текст появляется целиком после задержки. Полный ответ сохраняется сразу, а временное состояние генерации ведется отдельно в `src/hooks/use-mock-generation.ts`: перезагрузка во время печати восстанавливает завершенный ответ. Уход в другой разговор не прерывает его генерацию; удаление разговора и полный сброс отменяют таймеры.

Компоненты `src/components/generative-ui/` отображают расписание с подробностями пар, неделю с вкладками дней и фильтром занятий/дедлайнов, домашки с фильтром статуса и учебные материалы с поиском по названию, курсу и пути. Фильтры и раскрытие работают локально, без отправки сообщений; контекстные подсказки заполняют поле ввода, а отправка продолжает текущий разговор. Подробности конкретного задания доступны в диалоге, кнопки перехода открывают существующие разделы LMS. Поиск учебных материалов использует демонстрационную подборку курсов и не анализирует загруженные файлы из личной библиотеки. Изменение данных LMS и страницы отдельных файлов не реализованы.

Сценарий доступности учебных материалов: [локальная база и синхронизация](docs/material-sync-demo.md). Массовое скачивание заменено обновлением локального подготовленного набора; экспорт отдельных документов сохранен.
