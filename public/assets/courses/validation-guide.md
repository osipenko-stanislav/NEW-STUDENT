# Проверка качества модели

Локальный учебный пример NEW STUDENT. Не является официальным материалом курса.

1. Разделите данные на обучающую, валидационную и тестовую выборки.
2. Выберите метрику с учётом стоимости разных ошибок.
3. Сравните модель с простым базовым решением.
4. Подбирайте параметры на валидационных данных.
5. Оцените итоговый вариант на независимой тестовой выборке.
6. Запишите параметры, результат и ограничения эксперимента.
