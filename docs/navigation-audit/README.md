# Точки применения правил лэйаута и навигации NEW STUDENT

Проверка 19 ноября 2026. Chrome, desktop 1440×1000, светлая тема, локальные исходники HEAD 535a67c и текущий docs/layout.md. Цель — найти места применения согласованных правил, сохранив сетку, поля, панели и плотность. Приложение и документы проекта в этом проходе не менялись. Скриншоты и DOM-снимки получены заново в текущем проходе.

## Приоритет реализации

1. Общая адресация сущности и вкладки; валидация URL и ссылки вместо навигационных кнопок. Без этого нельзя закончить копирование и прямой вход.
2. Контекст возврата: подтверждённая внутренняя история, fallback, прокрутка уроков, локальные фильтры и панели просмотра. Сохранить уже работающие возвраты из поиска и Навигатора.
3. Композиция: реальные крошки урока/ДЗ/Хэндбука, меню действий страницы, порядок навигации/H1/тулбара в ведомости. Затем семантический H1 каталога и общая левая ось чтения.

## 4. Домашка

Состояние: **Приоритет: контекст возврата и родительская навигация**.

Есть «Назад», но курс стоит отдельной кнопкой под H1; над H1 расположены статусы. Для целевой цепочки добавить перед H1 родительские ссылки «Курсы → название курса» и согласовать расположение метаданных. При необходимости сохранить рядом контекстный «Назад»; одинаковые назначения не дублировать. Возврат из ДЗ в урок потерял прокрутку: до перехода 2182 px, после возврата 0. Причина подтверждена кодом: CoursesWorkspace сбрасывает scrollTop при routeKey. PageBackButton вызывает только history.back(), без подтверждённого внутреннего контекста или fallback для прямого входа; риск выхода за пределы приложения оценён по коду, не воспроизводился внешним переходом. Копирования ссылки/отправки в Навигатор на странице нет.

## Границы проверки

Это проверка desktop-навигации и конкретных переходов, а не полный аудит всех разделов или соответствия WCAG. Мобильная навигация по договорённости вынесена отдельно. Тёмная тема, масштаб текста, все фильтры и комбинации источников перехода, прямой вход после будущего добавления URL, вся клавиатурная навигация и все якоря не проверялись. Сценарий программы курса проверен клавиатурой через Escape и на возврат фокуса. По коду отдельно подтверждены отсутствие общего URL-кодирования вне Хэндбука и отсутствие защиты в PageBackButton. Не трактовать целевые возможности как уже реализованные.

Промежуточный 18-navigator-response.png отклонён: пойман в фазе появления ответа; вместо него используется 20-navigator-return-stable.png. 17-syllabus-catalog.png отклонён как доказательство отдельного каталога: он показывает прежнюю локальную страницу, так как ссылка открыла внешнюю вкладку. Внешний каталог снят отдельно в 18-external-syllabus.png. В папке `screenshots/` сохранены принятые скриншоты; JSON-файлы рядом с ними содержат DOM-снимки, заголовки и адреса.
