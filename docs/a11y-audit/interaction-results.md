# Interaction results

## Выполнено

- Локальное приложение открыто реальным Chrome Headless.
- Сняты DOM и PNG стартового Навигатора на 375, 768, 1366 и 1440 px.
- В DOM присутствуют доступные имена для основных действий (например, Навигатор, Библиотека, Виджеты, голосовой ввод, отправка запроса), а также status/alert-паттерны.

## Не выполнено

Клавиатурный Tab-порядок, Escape/Arrow, focus return, переключение вкладок, поиск, фильтры, календарь, отправка домашки, Late Days, уведомления, Status Island и фактические `getBoundingClientRect()` не проверены: интерактивный CDP-клиент и axe-core недоступны.

Подтверждённых keyboard/ARIA WCAG-нарушений: **0**.
