# Runtime findings

Дата проверки: 2026-11-17. Runtime-снимки получены Chrome Headless из локального Vite-приложения (`http://127.0.0.1:5173/`) для стартового экрана Навигатора.

## Подтверждённые нарушения WCAG

**0.** В выполненном объёме ни одного нарушения не подтверждено. Computed-style контраст, клавиатурные переходы и assistive-technology API не были измерены, поэтому отсутствие находки не является полным доказательством соответствия.

## UX-находки без формального нарушения

**0 подтверждённых.** В DOM-снимках стартового экрана обнаружены именованные интерактивные элементы и status/alert-регионы; визуальная оценка остальных экранов требует отдельного открытия состояний.

## Непроверенные области

- Контраст после alpha-композиции, hover/selected/focus/error/success/disabled.
- Фактические размеры hit target и порядок Tab.
- Возврат фокуса из Dialog/Popover/Sheet.
- Масштабирование 200/400% и настройки размера текста.
- Экранные разделы, кроме стартового Навигатора.
