# Typography matrix

Chrome Headless отрендерил DOM стартового Навигатора на четырёх ширинах; HTML-снимки находятся в `runtime-snapshots/home-*.html`.

Computed `font-size`, `line-height`, browser zoom 200/400% и пользовательский text-size runtime не измерялись, поэтому таблица размеров не заполняется предположениями.

| Область | Runtime-статус |
|---|---|
| Навигатор, 375/768/1366/1440 | DOM и screenshot captured |
| Курсы, домашка, расписание, ведомости, Late Days, хэндбук, библиотека, уведомления, настройки | Не открывались в браузере |
| 200%/400% zoom и text-size settings | Не проверены |

Малый размер текста сам по себе не классифицируется как WCAG-нарушение.
