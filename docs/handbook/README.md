# Перенос хэндбука

Источник: https://note.cu.ru/at/db3f475e-b70a-4423-abc0-b030db55c80b
Дата получения: 13 ноября 2026 года.
Роль: студент первого курса бакалавриата Школы технологий ЦУ.

Перенесены 96 страниц с исходной иерархией. Повторная публикация программы бакалавриата объединена со страницей в ветке Школы технологий; старый идентификатор обрабатывается как псевдоним. Синхронизируемые блоки раскрыты при импорте, поэтому статьи читаются из локальных JSON, без обращения к API TEAMLY во время чтения. Тексты импортированы из источника; фильтрация аудитории не заменяет официальное обновление правил.

Интерфейс: дерево слева вторым уровнем после основного меню, хлебные крошки, переход к родительской странице, поиск по названиям и полным текстам, оглавление статьи, раскрывающиеся инструкции, таблицы, вкладки, вложения и форма исследовательского трека. На узких экранах дерево открывается в панели, оглавление — внутри статьи. Используются компоненты и тема shadcn/ui, локальный PT Root UI и настройки масштаба текста.

Адреса: `/?handbook=<article-id>#<heading-id>`. Можно копировать ссылку, открывать ее в другой вкладке и возвращаться через историю браузера. Параметр хэндбука удаляется при переходе в другой раздел.

Отбор: исключены другие школы, магистратура, ВКР, программы для уже обучающихся на двойном дипломе, предложения карьеры со второго/третьего курса и архив проектов 2025 года. Сохранены общие документы, финансы, здоровье, поддержка, кампус, сервисы, студенческая жизнь и доступные первокурсникам карьерные возможности. Внутри общих страниц удалены явные ветки других ролей; обзор будущей траектории бакалавриата сохранен. Условия гражданства, формы оплаты, здоровья и проживания не угадывались: эти инструкции сохранены с исходными условиями.

Ограничения источника:

- Синхронизируемый блок категории «Документы и учеты» возвращает HTTP 403 без авторизации. Дерево категории и все пять вложенных инструкций доступны и перенесены. Недоступный текст не заменялся выдуманным.
- В исходной статье «Искусственный интеллект» есть незавершенная загрузка изображения без URL. Пустой блок пропущен.
- Изображения и файлы используют исходные публичные адреса; формы, Time, сервисы и документы вне выбранного дерева открываются на своих исходных адресах. Их доступность зависит от соответствующего сервиса.

Технические данные и исключенные страницы: [import-report.json](import-report.json).
Повторный импорт: `python3 scripts/import-handbook.py`. Скрипт кэширует прочитанные ответы в системной временной папке `cu-handbook-cache`; для полного обновления источника сначала очистить эту папку. Запросы к источнику только на чтение.
