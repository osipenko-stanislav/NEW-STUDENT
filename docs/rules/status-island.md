# Статусы действий студента

Айленд показывает операции и изменения, инициированные студентом. Переходы, открытие панелей, табы, фильтры, ввод отдельных символов и восстановление данных его не вызывают. Айленд закреплён по центру глобального header, на 12 px ниже его фактического нижнего края; при изменении ширины меню и на мобильной ширине положение пересчитывается.

## Владельцы

- `src/lib/action-status.ts` — непостоянная очередь операций: `begin`, `update`, `finish`, `report`, `dismiss`. Без React и без хранения в браузере. События отправляются из обработчиков операций после фактического результата, а не из общего перехватчика кликов.
- `src/components/StatusIsland.tsx` — единственный экземпляр в App, подписка через `useSyncExternalStore`, раскрытие, таймеры, клавиатура и live region.
- `src/styles/status-island.css` — композиция с существующими цветами, шрифтами, скруглением и тенью Cupertino. Подключается только через `src/index.css`.
- `statusIslandParameters` в `src/lib/motion-recipes.ts` — единый motion-контракт без глобального множителя длительности.

## Жизненный цикл

Айленд используется для длительных операций, скачивания, очистки данных и значимых учебных результатов. Если результат сразу виден в месте действия, отдельный глобальный статус не создаётся. Асинхронная операция получает отдельный ID и состояние `running`; процент используется только при наличии прогресса в самой операции. Завершение меняет существующее событие, а не создаёт второй статус загрузки. Успех показывается после сохранения/результата. Для скачивания сообщается передача файла браузеру: завершение записи на диск интерфейсу неизвестно.

Последнее действие/завершение показано в компактной форме. За ним видны до двух слоёв очереди. По hover мышью, клику/тапу или Enter/Space раскрывается список с подробностями. Escape сворачивает список и возвращает фокус на айленд. Автоматическое появление фокус не забирает. При удалении строки фокус остаётся в списке.

Успех скрывается через 4 секунды. Чтение раскрытого списка приостанавливает таймер; после сворачивания отсчёт начинается заново. Ошибка не исчезает автоматически, её можно закрыть. Выполняемую операцию скрыть нельзя. В очереди сохраняются до шести успешных результатов; ошибки и активные операции не вытесняются успехами. Повторные результаты одной операции объединяются по ключу. Ревизия защищает обновлённый статус от старого таймера. После сброса сессии поздний результат прежней операции не восстанавливает очередь.

Во время модального Dialog/Sheet айленд виден в компактном виде, но не перехватывает управление и фокус модального окна. Таймер приостановлен; после закрытия диалога результат доступен ещё 4 секунды. Поповеры не считаются модальными окнами.

## Подключённые операции

| Область | Действия |
| --- | --- |
| Настройки | Сброс, запрос постоянного хранения, экспорт и очистка; ошибки сохранения |
| Навигатор | Очистка истории; отправка сообщений и действия с отдельными разговорами обходятся локальной обратной связью |
| Материалы | Сохранение файлов, удаление файлов/очистка библиотеки, скачивание, ручная синхронизация |
| Домашки | Сохранение и отправка решения, ошибки проверок |
| Late Days | Подтверждённый одиночный/массовый перенос и ошибки; повторное применение одного плана не создаёт второй успех |
| Курсы | Ошибки сохранения порядка карточек |

Отправка сообщений и комментариев, прочтение одного/всех уведомлений, закрепление и переименование чата, выбор темы/настроек, перестановка курсов, добавление/удаление вложений и запуск таймера не создают общий статус успеха. Голосовой ввод показывает запись и распознавание только в своей панели. Ошибки чата, вложений и прочтения уведомлений остаются рядом с содержимым.

Автоматическая подготовка/проверка учебных материалов не создаёт статус пользовательского действия. Несуществующие действия «в закладки» не имитируются: показываются только реально реализованные операции.

Состояния кнопок, полей и локальные ошибки сохраняются. Повторные общие сообщения об успехе в настройках, форме решения и каталоге заменены айлендом. Предметные подтверждения, например новые сроки и расход Late Days, остаются в своём контексте.

## Анимация и доступность

Источник: [Kokonut Status Island](https://kokonutui.com/docs/navigation/status-island), [исходник registry](https://kokonutui.com/r/status-island.json), лицензия [MIT, Copyright (c) 2025 kokonutUI](licenses/kokonut-ui.txt).

Сохранены параметры примера: morph spring 450 ms / bounce 0.18, смена 220 ms / ease `[0.23, 1, 0.32, 1]`, появление/уход на 8 px с blur 4 px, смена содержимого ±6 px, слои очереди с шагом 5 px и scale 0.94/0.88. Иконки и числа используют существующие `StateIcon` и `AnimatedNumber`.

Настройки интенсивности и системный reduced motion проходят через `useAppMotion`. При minimal/reduced отключены morph, пространственный сдвиг, blur и вращение индикатора. Очередь, тексты, клавиатура и управление сохраняются. Live region сообщает результат, не озвучивая каждый процент прогресса.
