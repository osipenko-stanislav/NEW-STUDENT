# Правила NEW STUDENT

Эта папка содержит публичную копию правил интерфейса и разработки проекта. Её можно читать напрямую из GitHub при работе GPT или другого внешнего инструмента.

- [AGENTS.md](./AGENTS.md) — рабочие ограничения, продуктовые правила, навигация, тексты и проверки.
- [DESIGN.md](./DESIGN.md) — визуальная система, компоненты, поверхности, motion и владельцы стилей.
- [layout.md](./layout.md) — сетка, ширины, отступы, контролы и правила второго уровня навигации.
- [cupertino.md](./cupertino.md) — адаптация Cupertino.
- [motion-component-inventory.md](./motion-component-inventory.md) — каталог motion-контрактов.
- [motion-recipes.md](./motion-recipes.md) — рецепты и состояния движения.
- [status-island.md](./status-island.md) — правила глобальной обратной связи действий.
- [late-days-demo.md](./late-days-demo.md) — UX-правила демонстрационного сценария Late Days.

Источниками этих документов остаются корневой `AGENTS.md`, `DESIGN.md` и документы в `docs/`. При изменении правил обновляй обе версии.
