## Принятые правила и уточнения
- Макеты Figma задают структуру и сценарии; сохранять существующий Cupertino, компоненты и паттерны проекта. Пользователь отдельно потребовал переиспользовать стиль таблиц ведомостей, включая скругления.
- De-island, don't flatten: оправданные поверхности сохранять. Оценка, максимальный балл и дедлайн домашки находятся в одном острове.
- Обсуждение домашки: без пузырей и общей Card, composer по паттернам Навигатора, аватар из навигации; новые сообщения без предустановленных реакций. Файлы локально в IndexedDB; планирование работает при открытом обсуждении. Код обсуждения и smoke/audit отчёты уже в предыдущем коммите ce4b525.
- «🔥 Я в огне» — точный текст кнопки/саджеста. Оба используют тёплый градиент; в домашках компактный саджест как в Навигаторе, сохраняет планировщик Late Days.
- Таблицы: согласованные заголовки и отступы, сохранять sticky. Mobile менять лишь при подтверждённом дефекте.
- Подключать impeccable для UI-работы; не заявлять визуальную проверку без реального browser-run.
